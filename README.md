# AI Prompt Director

Локальное веб-приложение для AI-режиссёра: управление промптами для нейросетей и библиотека визуальных референсов по проектам.

## Возможности

### 📝 Промпты
- Три раздела по нейросетям: **Seedance 2.0**, **VEO OMNI GOOGLE**, **KLING**
- Добавление, редактирование, удаление промптов в каждом разделе
- Кнопка **Копировать** на каждой карточке + клик по карточке открывает модальное окно с полным текстом и большой кнопкой копирования

### 🎨 AI Image Reference
- Создание неограниченного количества проектов (например, «Проект 2к17»)
- Внутри проекта — персонажи
- У каждого персонажа — неограниченное количество фото-референсов с подписями ракурсов
- Drag & drop загрузка изображений, превью, просмотр на весь экран

### 💾 Хранение
- Все данные (включая изображения) сохраняются локально в **IndexedDB** браузера
- Ничего не отправляется на сервер
- Кнопки **Экспорт / Импорт** в JSON для бэкапа и переноса между устройствами/браузерами

## Запуск локально

Поскольку приложение использует IndexedDB, его желательно открывать через локальный HTTP-сервер (не как `file://`), иначе браузер может ограничить доступ к API.

### Вариант 1 — Python (есть в любой системе)

```bash
cd путь/к/папке/с/проектом
python3 -m http.server 8000
```

Открыть в браузере: <http://localhost:8000>

### Вариант 2 — Node.js

```bash
npx serve .
# или
npx http-server -p 8000
```

### Вариант 3 — VS Code

Установите расширение **Live Server** → правый клик на `index.html` → **Open with Live Server**.

### Вариант 4 — Просто открыть файл

Можно открыть `index.html` двойным кликом — в большинстве современных браузеров (Chrome, Firefox, Edge, Safari) IndexedDB работает и через `file://`. Если данные не сохраняются — используйте локальный сервер.

## Горячие клавиши

- **Esc** — закрыть модальное окно

## Бэкап

Нажмите **Экспорт** в нижней части боковой панели — получите `.json` файл со всеми промптами, проектами, персонажами и референсами (изображения хранятся как base64 внутри JSON).

Импорт работает в обратную сторону. Записи с одинаковым ID будут перезаписаны.
